# NIFTY AI TRADER PRO — Version 2.1

## Android app features
- Home dashboard: virtual starting capital ₹5,00,000, available virtual balance, open positions and realized P&L.
- Watch tab: NIFTY 50, BANK NIFTY, FINNIFTY and MIDCAP NIFTY watchlist. Prices stay blank until a verified feed is connected.
- Paper tab: create virtual BUY/LONG or SELL/SHORT trades using a manually entered assumed price, quantity, stop-loss and target. Directional SL/target validation is included.
- Positions tab: view open virtual positions, manually check an entered assumed price against stop-loss/target, or close at an assumed exit price.
- History tab: closed virtual trades and realized simulated P&L.

## Important
PAPER TRADING ONLY. The app does not connect to Angel One, does not display live quotes, and does not send orders to any broker. All prices entered in paper orders/position checks are manual assumed prices. Stop-loss/target checks are user-triggered, not live automatic execution. ₹5,00,000 is virtual only.

## Build
The GitHub Actions workflow in the repository extracts this ZIP and builds `app-debug.apk`.
