# NIFTY AI TRADER PRO V5.22 — Synthetic visual analysis

- Adds a synthetic OHLC candlestick chart with calculated EMA 9/21/50 overlays.
- Adds volume bars and an RSI position meter using the corresponding historical-analysis response.
- Shows MACD, signal, and histogram values in a compact panel.
- Chart renders only from the synthetic candle sample fetched by the existing paper-only endpoint.
- No live data, forecasts, BUY/SELL calls, or real broker orders are introduced.

APK build and on-device verification must be confirmed through GitHub Actions and the installed app.
